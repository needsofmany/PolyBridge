# Agent working rules

- Public project attribution is Needs of the Many.
- Use project identities supplied by maintainers. Do not infer personal attribution from machine accounts or local configuration.
- Maintainers decide architecture and scope.
- Implement authorized work. Report unresolved decisions.
- The authoritative website source is `website/`.
- The planned application source is `app/src`.
- `wwwroot` frontend files are generated copies.
- Preserve PolyBridge and PluralBridge as separate applications and databases.
- Do not implement future integrations merely because they are discussed.
- Do not run automatic builds, commits, pushes, merges, or deployments unless explicitly requested.
- Keep reports concise and changes focused.
- Preserve third-party copyright and license notices.
